# StreetJev

Настольное приложение для Windows: снимок области экрана или выбранного окна → imajev-4b →
накопление географических гипотез → карта стран и административных регионов.
Модель получает только выбранное изображение. Интерфейс, сервис модели, установщик,
карта и тесты находятся в одном репозитории.

## Быстрый запуск

Нужен [uv](https://docs.astral.sh/uv/). Python 3.12 и зависимости устанавливаются через uv.

```powershell
uv sync
uv run streetjev --demo
```

Демо использует **синтетические данные**, не делает снимков и не вызывает модель.
Нажмите «Добавить демо-наблюдение» несколько раз, затем «К лидеру» и «Регионы».

Для настоящего анализа один раз установите модель:

```powershell
uv run python services/imajev/manage.py setup
```

Скачиваются базовая Qwen3.5-4B, адаптер imajev и PyTorch с CUDA 12.8. Нужны интернет,
NVIDIA GPU и запас места (ориентир 25–35 ГБ с окружением и кэшами). Установщик продолжает
загрузки при повторном запуске. Все файлы сервиса размещаются в `.runtime/` этого репозитория.

Затем запустите приложение вместе с сервисом:

```powershell
.\run.ps1 -WithModel
```

Первый запуск модели требует времени. Журнал: `data/imajev.stderr.log`.
После закрытия приложения скрипт завершит запущенный им сервис.

Можно запускать вручную в двух терминалах из корня проекта:

```powershell
uv run python services/imajev/manage.py start
uv run streetjev
```

В таком случае сервис остаётся работать до Ctrl+C в его терминале.
`uv run python main.py` также запускает приложение.

## Работа

1. Выберите область на одном из мониторов или окно. Для аппаратно ускоренных окон,
   возвращающих чёрное изображение, используйте область. Область должна оставаться видимой,
   не закрывайте её окном карты. Захват окна выполняется через Windows PrintWindow.
2. Нажмите «Анализировать кадр» либо **Ctrl+Alt+G**. Снимок виден в левой панели.
   Можно включить автозахват, интервал по умолчанию — 5 секунд, либо открыть файл изображения.
3. Переключите карту на «Регионы»; двойной щелчок по стране приближает её.
4. **Ctrl+Alt+R** или «Новый раунд» сбрасывает накопленные знания.

Сервис по умолчанию использует `http://127.0.0.1:18765`.
Горячие клавиши настраиваются и работают вне фокуса приложения. Конфликты клавиш показываются
в статусе. При занятости модели новые тики таймера пропускаются: очереди устаревших кадров нет.
Сброс доступен во время запроса; его результат не попадёт в новый раунд. Следующий анализ
станет доступен после завершения старого запроса или таймаута.

Страны и территории: **240**, регионы: **4 580**. Карта работает без сети.
При отсутствии регионального наблюдения страна остаётся серой на региональном слое.
Её оценка доступна в подсказке и на слое стран.

## Что реализовано и что означает оценка

- Страны определяются одним choice-вопросом, регионы — условными вопросами для 3 ведущих стран.
  Количество ветвей меняется в настройках; 0 означает только страны.
- Оценка раунда — взвешенное среднее ответов. Вес кадра: `новизна × (1 − unknown)`.
  Повторение одной оценки не повышает её до 100%; результат по стране остаётся в диапазоне
  оценок отдельных учтённых кадров. Столбцы «Раунд» и «Кадр» показывают обе оценки рядом.
- Простая оценка новизны по миниатюре 32 × 32, сравниваемой с последними 256 принятыми кадрами.
  Точные повторы миниатюры отсеиваются за весь раунд.
- SQLite хранит исходные ответы API, нормализованные наблюдения, веса и итог раунда.
  Сами скриншоты на диск не записываются. Новый запуск начинает новый раунд;
  старые записи остаются в журнале для последующего анализа, автоматического восстановления пока нет.
- Экспорт текущего распределения в JSON. Настройки, журнал и БД — в `data/`, путь меняется через `--data-dir`.

Проценты — **некалиброванные для геолокации оценки**, не измеренная вероятность правильного ответа.
Пороги новизны — эвристика MVP. Региональная оценка является совместной
`P(страна) × P(регион | страна)`. Неизвестность показана отдельно и не является ещё одной страной.
Усреднение устраняет усиление оценок перемножением, но не исправляет систематическую ошибку модели.
Высокая оценка одного кадра может остаться высокой; согласие кадров не является калибровкой точности.
Точность и задержка требуют проверки на реальных сериях Street View.

Карта по умолчанию использует **относительную логарифмическую шкалу** для текущего слоя.
Легенда показывает реальные оценки, например 0,009–0,083%, а не искусственные 0–100%.
Настройка «Абсолютная шкала» возвращает фиксированную шкалу 0–100%.
Масштабирование карты не меняет цветовую нормализацию. Равные оценки не образуют ярких пятен.
Переключатель «Последний кадр» показывает исходные ответы; по умолчанию отображается раунд.

Chipoint, H3/S2, learned fusion, benchmark и обучение калибратора — следующие этапы.
Текущая карта окрашивает административные полигоны, а не строит непрерывное поле координат.

## Структура

```text
src/streetjev/
  domain/          # GeoRound, GeoEvidence, география и правила накопления
  application/     # сценарии, Session, порты GeoExpert и RoundRepository
  infrastructure/  # imajev HTTP, захват Windows, SQLite, геоданные, демо
  presentation/    # PySide6: окно, карта, выбор области, горячие клавиши
  assets/          # автономная карта Natural Earth
services/imajev/   # установка, запуск, статус и закреплённые версии модели
scripts/           # сборка географии и проверки интерфейса
tests/             # доменные и интеграционные проверки
.runtime/          # окружение и веса сервиса, исключены из Git
data/              # локальные настройки и журнал раундов, исключены из Git
```

Архитектура — модульный монолит с DDD-ядром и портами/адаптерами. GPU-сервис выделен
в процесс для изоляции зависимостей; предметные правила не зависят от Qt, CUDA, HTTP и SQLite.

## Проверки

```powershell
uv run pytest -q
uv run ruff check src scripts services tests
uv run python scripts/smoke_ui.py
uv run python scripts/smoke_windows.py
uv run python scripts/replay_rounds.py
```

Smoke-проверка сохраняет картинки интерфейса в `artifacts/ui/`; там же тестовая БД.
Windows smoke кратко открывает собственное тестовое окно и проверяет захват только его содержимого.
Данные карты пересобираются командой `uv run python scripts/build_geography.py`.
`replay_rounds.py` читает старые раунды без изменения БД и записывает сравнение алгоритмов
в `artifacts/confidence-replay.json`. Используются сохранённые веса новизны, изображения не требуются.
