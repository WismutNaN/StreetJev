# StreetJev

Настольное приложение для Windows: снимок области экрана или выбранного окна → imajev-4b и опциональный Chipoint →
накопление географических гипотез → карта стран и административных регионов.
Модель получает только выбранное изображение. Интерфейс, сервис модели, установщик,
карта и тесты находятся в одном репозитории.

## Быстрый запуск

Нужен [uv](https://docs.astral.sh/uv/). Python 3.12 и зависимости устанавливаются через uv.

```powershell
uv sync
uv run streetjev --demo
```

Демо использует **синтетические данные**, не делает снимков и не вызывает модель.
Нажмите «Демо-кадр» несколько раз, затем «Лидер» и «Регионы».

Для настоящего анализа один раз установите модель:

```powershell
uv run python services/imajev/manage.py setup
```

Скачиваются базовая Qwen3.5-4B, адаптер imajev и PyTorch с CUDA 12.8. Нужны интернет,
NVIDIA GPU и запас места (ориентир 25–35 ГБ с окружением и кэшами). Установщик продолжает
загрузки при повторном запуске. Все файлы сервиса размещаются в `.runtime/` этого репозитория.

Затем запустите приложение вместе с сервисом:

```powershell
.\run.ps1 -WithModel
```

Первый запуск модели требует времени. Журнал: `data/imajev.stderr.log`.
После закрытия приложения скрипт завершит запущенный им сервис.

Можно запускать вручную в двух терминалах из корня проекта:

```powershell
uv run python services/imajev/manage.py start
uv run streetjev
```

В таком случае сервис остаётся работать до Ctrl+C в его терминале.
`uv run python main.py` также запускает приложение.

## Необязательный Chipoint

```powershell
uv run python services/chipoint/manage.py setup  # один раз
.\run.ps1 -WithModel -WithChipoint
```

Включите **Chipoint** в шапке. По умолчанию установлен профиль SigLIP2 SO400M + street gallery:
4,89 млн кадров, около 5 ГБ индекса плюс энкодер и окружение. Все загрузки — внутри `.runtime/`.
imajev показывает результат сразу; Chipoint дополняет тот же кадр по готовности.
Если Chipoint занят, недоступен или превысил таймаут, основной анализ продолжается.
Выключение переключателя возвращает накопленные оценки imajev, сохраняя раунд.
Для запуска без загруженного второго сервиса используйте обычный `-WithModel`.

Реализован **street retrieval**, без финального reranker: его точные признаки не опубликованы,
и официальное демо также отключает этот этап. Прирост accuracy пока не измерен.
Подробнее о профилях, API и ограничениях — [сервис Chipoint](services/chipoint/README.md).

## Работа

1. Выберите область на одном из мониторов или окно. Для аппаратно ускоренных окон,
   возвращающих чёрное изображение, используйте область. Область должна оставаться видимой,
   не закрывайте её окном карты. Захват окна выполняется через Windows PrintWindow.
2. Нажмите «Снимок» либо **Ctrl+Alt+G**. Снимок виден в карточке гипотез поверх карты.
   Можно включить автозахват, интервал по умолчанию — 5 секунд, либо открыть файл изображения.
3. Переключите карту на «Регионы»; двойной щелчок по стране приближает её.
4. Когда ответ известен, нажмите **«Ответ»** и кликните по правильному месту на карте.
   Сохраняются координаты, страна и административный регион; розовая точка показывает отметку.
   Приближение и перетаскивание доступны. Повторное нажатие «Ответ» позволяет исправить точку.
   Сбор новых кадров после отметки останавливается, оценки раунда остаются прежними.
5. **Ctrl+Alt+R** или «Сброс» начинает следующий раунд. Сохранённые ответы остаются в базе.

«Автофокус» приближает группу лидирующих стран/регионов. При сопоставимых гипотезах в разных
частях света остаётся весь мир. Ручная навигация выключает автофокус; переключатель возвращает его.

Сервис по умолчанию использует `http://127.0.0.1:18765`.
Горячие клавиши настраиваются и работают вне фокуса приложения. Конфликты клавиш показываются
в статусе. При занятости модели новые тики таймера пропускаются: очереди устаревших кадров нет.
Сброс доступен во время запроса; его результат не попадёт в новый раунд. Следующий анализ
станет доступен после завершения старого запроса или таймаута.

Страны и территории: **240**, регионы: **4 580**. Базовая карта полигонов работает без сети.
При отсутствии регионального наблюдения страна остаётся серой на региональном слое.
Её оценка доступна в подсказке и на слое стран.

### Подробная карта и зоны внутри региона

**«Детали»** включает подложку OpenStreetMap: города, населённые пункты, дороги и, при приближении,
улицы и здания. Колесо приближает до уличного масштаба; двойной клик на подробном масштабе тоже
приближает. Заливка гипотез полупрозрачная. В режиме «Ответ» заливка убирается, чтобы точно поставить
метку. Координаты сохраняются независимо от размера зоны.

Для новых участков подложки нужен интернет. Загружается только текущий вид, максимум четыре запроса
одновременно; HTTP-кэш хранится в `data/map-cache`, до 256 МБ. Внешний сервер получает номера тайлов,
изображения захваченного экрана ему не отправляются. При недоступности сети остаются доступные тайлы
и исходная карта полигонов. Массовой загрузки городов/стран нет; соблюдается
[политика сервера OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/).
В деморежиме сетевой слой изначально выключен.

Слой **«Зоны · 10 км»** использует координаты найденных Chipoint кадров. Близкие совпадения объединяются
в ячейки порядка 10 × 10 км, с поправкой ширины по широте. Это географические участки поиска, а не
официальные округа и не обещание ошибки менее 10 км. Ячейки на границах визуально обрезаются по
родительскому региону из Natural Earth; его границы обобщены и могут отличаться от подробной подложки.

Оценки зон накапливаются с весами новизны кадров и вкладом Chipoint. Поддержка зоны не может превышать
поддержку её региона и страны. Новые кадры без локальных данных не создают точность внутри региона;
последний кадр и весь раунд доступны отдельно. Отключение Chipoint убирает его зоны из раунда.
Без координатных кандидатов слой пустой: imajev сам по себе пока определяет страну/admin1.

В таблице зон показаны координаты центра и родительский регион. Двойной клик по строке или кнопка
«Лидер» приближает нужную область; рядом видны названия городов на подложке. Дополнительного запроса
к GPU для построения зон нет. Реальная точность субрегиональной локализации ещё требует разметки.

## Калибровка по правильным ответам

Калибратор запускается отдельно от интерфейса, без GPU и сервисов моделей:

```powershell
uv run python scripts/calibrate.py
```

Он читает `data/rounds.sqlite3`, заново рассчитывает **исходные** ответы моделей и сохраняет
`artifacts/calibration/report.json` и `profile.json`. Подбираются температуры стран и регионов imajev,
температура Chipoint, вес объединения и сила поправок по движению, полушарию и покрытию.
Это калибровка оценок моделей и настроек, **не обучение весов нейросетей**. Скриншоты не сохраняются;
для этого алгоритма достаточно ответов API и правильных координат.

Минимум — 12 географических ячеек с разметкой, желательно 50–100 разнообразных мест.
Целые раунды одной ячейки 0,25° попадают только в одну часть выборки: обучение или проверку.
Подбор идёт только на обучающей части. Отчёт сравнивает log loss, долю правильных стран и регионов,
ошибку уверенности и наличие региональной ветви правильной страны. Демо исключается.

Чтобы применить результат:

```powershell
uv run python scripts/calibrate.py --apply
```

Профиль заменяет `data/calibration.json` **только если** log loss на проверочной части снизился,
а доля правильных стран и регионов не ухудшилась. Сравнение идёт с действующим совместимым профилем,
если он есть, иначе со стандартными настройками. Предыдущий профиль остаётся в
`data/calibration.previous.json`. Приложение загрузит новый профиль после перезапуска.
Для возврата к стандартным настройкам уберите `data/calibration.json`.

При нескольких версиях моделей выбирается наиболее представленная версия imajev и совместимая
выборка Chipoint; исключённые раунды перечислены в отчёте. Конкретную версию можно задать
`--imajev-model "точная версия"` и `--chipoint-model "точная версия"`.
Другая база: `--database путь/rounds.sqlite3`; отчёты: `--output путь/отчёты`.
Приложение проверяет версии моделей и каталог перед применением параметров.

Калибровка не добавляет отсутствующие ответы о регионах и кандидатов Chipoint. При смене температур
будущие региональные запросы могут выбрать другие ветви; офлайн-проверка использует только уже
сохранённые ветви. Результат на небольшой выборке не гарантирует прироста на новых местах;
после применения стоит собрать независимые контрольные раунды.

## Что реализовано и что означает оценка

- Страны определяются одним choice-вопросом, регионы — условными вопросами для 3 ведущих стран.
  Количество ветвей меняется в настройках; 0 означает только страны.
- Оценка раунда — взвешенное среднее ответов. Вес кадра: `новизна × (1 − unknown)`.
  Повторение одной оценки не повышает её до 100%; результат по стране остаётся в диапазоне
  оценок отдельных учтённых кадров. Столбцы «Раунд» и «Кадр» показывают обе оценки рядом.
- Простая оценка новизны по миниатюре 32 × 32, сравниваемой с последними 256 принятыми кадрами.
  Точные повторы миниатюры отсеиваются за весь раунд.
- SQLite хранит исходные ответы API, нормализованные наблюдения, веса и итог раунда.
  Сами скриншоты на диск не записываются. Новый запуск начинает новый раунд;
  старые записи остаются в журнале для последующего анализа, автоматического восстановления пока нет.
- Экспорт текущего распределения в JSON. Настройки, журнал и БД — в `data/`, путь меняется через `--data-dir`.

Без собственного профиля проценты — **некалиброванные для геолокации оценки**.
И после калибровки на небольшой выборке их нельзя считать подтверждённой вероятностью правильного ответа.
Пороги новизны — эвристика MVP. Региональная оценка является совместной
`P(страна) × P(регион | страна)`. Неизвестность показана отдельно и не является ещё одной страной.
Усреднение устраняет усиление оценок перемножением, но не исправляет систематическую ошибку модели.
Высокая оценка одного кадра может остаться высокой; согласие кадров не является калибровкой точности.
Точность и задержка требуют проверки на реальных сериях Street View.

Карта по умолчанию использует **относительную логарифмическую шкалу** для текущего слоя.
Легенда показывает реальные оценки, например 0,009–0,083%, а не искусственные 0–100%.
Настройка «Шкала 0–100%» возвращает абсолютную шкалу.
Масштабирование карты не меняет цветовую нормализацию. Равные оценки не образуют ярких пятен.
Переключатель «Кадр» показывает оценку последнего учтённого кадра; по умолчанию отображается раунд.
При включённом Chipoint кадр объединяет доступных экспертов с весами по умолчанию 65/35 и поправкой на unknown.
Собственный профиль может изменить эти веса.
Исходные ответы каждого эксперта сохраняются отдельно и доступны для воспроизводимого сравнения.

H3/S2, spatial kernels, benchmark и обучение весов нейросетей — следующие этапы.
Текущая карта окрашивает административные полигоны и дискретные зоны поиска; непрерывного поля пока нет.

## Структура

```text
src/streetjev/
  domain/          # GeoRound, GeoEvidence, география и правила накопления
  application/     # сценарии, Session, порты GeoExpert и RoundRepository
  infrastructure/  # imajev HTTP, захват Windows, SQLite, геоданные, демо
  presentation/    # PySide6: окно, карта, выбор области, горячие клавиши
  assets/          # автономная карта Natural Earth
services/imajev/   # установка, запуск, статус и закреплённые версии модели
services/chipoint/ # необязательный поиск по галерее Street View, отдельное окружение
scripts/           # сборка географии и проверки интерфейса
tests/             # доменные и интеграционные проверки
.runtime/          # окружение и веса сервиса, исключены из Git
data/              # локальные настройки и журнал раундов, исключены из Git
```

Архитектура — модульный монолит с DDD-ядром и портами/адаптерами. GPU-сервис выделен
в процесс для изоляции зависимостей; предметные правила не зависят от Qt, CUDA, HTTP и SQLite.

## Проверки

```powershell
uv run pytest -q
uv run ruff check src scripts services tests
uv run python scripts/smoke_ui.py
uv run python scripts/smoke_windows.py
uv run python scripts/replay_rounds.py
```

Smoke-проверка сохраняет картинки интерфейса в `artifacts/ui/`; там же тестовая БД.
Windows smoke кратко открывает собственное тестовое окно и проверяет захват только его содержимого.
Данные карты пересобираются командой `uv run python scripts/build_geography.py`.
`replay_rounds.py` читает старые раунды без изменения БД и записывает сравнение алгоритмов
в `artifacts/confidence-replay.json`. Используются сохранённые веса новизны, изображения не требуются.
