# Интерфейс StreetJev

Карта занимает рабочую область. Первая строка шапки: «Область», «Окно», «Файл», «Снимок»,
«Авто» с интервалом, «Сброс», переключатель Chipoint, экспорт и настройки. Во второй строке
источник и управление картой: страны/регионы, раунд/кадр, шкала, автофокус, мир и лидер.
Крупный логотип, вводные подписи, вкладки и постоянные пояснения убраны. Подробности — в подсказках.

Компактная карточка поверх карты показывает до 12 гипотез, без длинного хвоста оценок ниже
1% от лидера (первые три сохраняются). Высота соответствует строкам; пустая карточка скрыта.
Последний снимок появляется только после захвата. Настройки открываются отдельным диалогом.
Внизу одна строка статуса и цветовая легенда с реальными оценками.

## Сценарии

| Сценарий | Действия |
|---|---|
| Выбрать область | Кнопка → выделение прямоугольника на одном мониторе |
| Выбрать окно | Кнопка → выбор окна в списке |
| Снять кадр | Одна кнопка или Ctrl+Alt+G |
| Сбросить знания | Одна кнопка или Ctrl+Alt+R, без подтверждения |
| Посмотреть регион | Двойной щелчок по стране, либо «Регионы» и «Лидер» |
| Дополнить результат Chipoint | Переключатель в шапке, нужен запущенный локальный сервис |
| Проверить интерфейс без GPU | `--demo`, добавлять явно синтетические наблюдения |

Перемещение карты — перетаскивание, масштаб — колесо, возврат — «Мир».
В окне выбора области Escape отменяет операцию. Источник и настройки модели меняют раунд:
сведения разных источников/моделей не смешиваются незаметно.

## Состояния

| Состояние | Отображение |
|---|---|
| Пусто | Нейтральная карта, список гипотез пуст |
| Inference | Статус обработки; повторный анализ отключён, сброс доступен |
| Повтор кадра | Сообщение о пропуске, карта без изменений |
| Unknown | Показатель неизвестности последнего кадра, малое влияние на карту |
| Ошибка | Причина в статусе, автозахват остановлен |
| Ошибка/задержка Chipoint | Короткий статус рядом с переключателем, подробности в подсказке; imajev продолжает |
| Демо | Постоянная маркировка вверху, захват экрана отключён |
| Закрытие во время запроса | Ожидание основного worker; необязательный HTTP worker не удерживает окно |

Таблица показывает две колонки: «Раунд» — взвешенное среднее, «Кадр» — последний ответ.
Переключатель над картой меняет отображаемый набор и порядок гипотез в таблице. Для региона,
не исследованного на последнем кадре, стоит «—», даже если в истории раунда он уже есть.
Показатель «Согласие N/M» описывает совпадение лидеров кадров, не точность.
При включённом Chipoint столбец кадра содержит смесь доступных экспертов; поздний ответ
к более старому кадру не выдаётся за новый снимок. Отключение возвращает оценки imajev.

## Автофокус

Включён при старте/сбросе. Группа лидеров включает оценки не ниже 30% от максимальной;
она должна содержать не более 12 полигонов и покрывать хотя бы 55% доступной массы.
При ширине охвата более 110° или высоте более 95 единиц проекции остаётся карта мира.
Есть минимальный охват 30 × 22 единицы: приложение не приближает карту к крошечному полигону.
Если региональные запросы ещё не покрывают ведущие страны, охват выбирается по странам.
Ручное перемещение, колесо, «Мир» и «Лидер» выключают автофокус; переключатель возвращает его.
Это эвристика охвата, не изменение рейтингов. При геометрии через антимеридиан используется мир.

## Цвет

На региональном слое фон стран серый: массу страны нельзя окрашивать по шкале регионов.
Подсказка региона показывает совместную оценку, оценку внутри страны и оценку самой страны.

По умолчанию шкала относительная логарифмическая:

```text
x = (score − min_layer) / (max_layer − min_layer)
intensity = log(1 + 9x) / log(10)
```

Вся география текущего слоя использует единую шкалу; отдельные страны и viewport
не нормализуются независимо. Легенда строится обратным преобразованием и показывает
реальные оценки. Максимально яркий полигон может иметь оценку 0,083% — это видно в легенде
и подписи «Макс.». Цвет не означает вероятность правильного ответа.
При равных оценках слой нейтральный; пустой слой сообщает об отсутствии наблюдений.
Переключатель «Шкала 0–100%» задаёт абсолютный диапазон; выбор сохраняется в настройках.
Точность вывода малых процентов увеличена; значения почти 1 не округляются до «100%».
