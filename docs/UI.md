# Интерфейс StreetJev

Карта занимает рабочую область. Первая строка шапки: «Область», «Окно», «Файл», «Снимок»,
«Авто» с интервалом, «Сброс», «Ответ», переключатель Chipoint, экспорт и настройки. Во второй строке
источник и управление картой: раунд/кадр, шкала, автофокус, мир, лидер и детали.
Крупный логотип, вводные подписи, вкладки и постоянные пояснения убраны. Подробности — в подсказках.

Компактная карточка поверх карты показывает три ведущие страны, до двух регионов каждой и
ведущий административный подрегион (ADM2) в каждом из них и сильнейшее совпадение Chipoint.
Страна выделена жирным, дочерние строки — отступом; двойной клик приближает любой уровень.
Высота соответствует строкам; пустая карточка скрыта. При автоматическом приближении учитывается
занятое карточкой место, чтобы гипотезы оставались в открытой части карты.
Последний снимок появляется только после захвата. Настройки открываются отдельным диалогом.
Внизу одна строка статуса, ключ «Контур: страна · Заливка: регион/район · Точки: Chipoint» и шкала.

## Сценарии

| Сценарий | Действия |
|---|---|
| Выбрать область | Кнопка → выделение прямоугольника на одном мониторе |
| Выбрать окно | Кнопка → выбор окна в списке |
| Снять кадр | Одна кнопка или Ctrl+Alt+G |
| Сбросить знания | Одна кнопка или Ctrl+Alt+R, без подтверждения |
| Посмотреть регион | Двойной щелчок по региону/строке таблицы, либо «Лидер» |
| Посмотреть координаты | Клик или наведение на точку; двойной клик приближает |
| Раскрыть группу совпадений | Двойной клик по маркеру с количеством точек |
| Изменить круг поиска | Настройки → радиус Chipoint, 1–200 км, по умолчанию 20 км |
| Сохранить правильное место | «Ответ» → клик по карте; повторное нажатие позволяет исправить |
| Дополнить результат Chipoint | Переключатель в шапке, нужен запущенный локальный сервис |
| Проверить интерфейс без GPU | `--demo`, добавлять явно синтетические наблюдения |

Перемещение карты — перетаскивание, масштаб — колесо, возврат — «Мир».
В окне выбора области Escape отменяет операцию. Источник и настройки модели меняют раунд:
сведения разных источников/моделей не смешиваются незаметно.

## Состояния

| Состояние | Отображение |
|---|---|
| Пусто | Нейтральная карта, список гипотез пуст |
| Inference | Статус обработки; повторный анализ отключён, сброс доступен |
| Повтор кадра | Сообщение о пропуске, карта без изменений |
| Unknown | Показатель неизвестности последнего кадра, малое влияние на карту |
| Ошибка | Причина в статусе, автозахват остановлен |
| Ошибка/задержка Chipoint | Короткий статус рядом с переключателем, подробности в подсказке; imajev продолжает |
| Демо | Постоянная маркировка вверху, захват экрана отключён |
| Закрытие во время запроса | Ожидание основного worker; необязательный HTTP worker не удерживает окно |

Таблица показывает две колонки: «Раунд» — взвешенное среднее, «Кадр» — последний ответ.
Переключатель над картой меняет отображаемый набор и порядок гипотез в таблице. Для региона,
не исследованного на последнем кадре, стоит «—», даже если в истории раунда он уже есть.
Показатель «Согласие N/M» описывает совпадение лидеров кадров, не точность.
При включённом Chipoint столбец кадра содержит смесь доступных экспертов; поздний ответ
к более старому кадру не выдаётся за новый снимок. Отключение возвращает оценки imajev.

## Автофокус

Включён при старте/сбросе. Группа лидеров включает оценки не ниже 30% от максимальной;
она должна содержать не более 12 полигонов и покрывать хотя бы 55% доступной массы.
При ширине охвата более 110° или высоте более 95 единиц проекции остаётся карта мира.
Если наблюдавшиеся региональные ветви покрывают хотя бы 55% поддержки стран, минимальный охват
составляет 8 × 6 единиц проекции; иначе — 30 × 22. При выборе охвата страна заменяется её регионами
только при наличии наблюдения, остальные страны участвуют целиком. Масса не учитывается дважды.
Ручное перемещение, колесо, «Мир» и «Лидер» выключают автофокус; переключатель возвращает его.
Это эвристика охвата, не изменение рейтингов. При геометрии через антимеридиан используется мир.

## Цвет

Страны показаны цветной обводкой, регионы — полупрозрачной заливкой, совпадения Chipoint —
точками с поисковыми кругами. Все три уровня используют палитру бирюзовый → песочный → оранжевый.
При приближении внутри региона появляются настоящие административные районы ADM2.
Поддержанные районы получают собственную заливку; фон родительского региона ослабляется.
Их поддержка вычисляется по координатам Chipoint, отсутствующие свидетельства не заменяются
равномерными оценками. Цвет ADM2 нормализуется отдельно; это не вероятность правильного ответа.
В обзоре множества стран сохраняются контуры стран и заливка ADM1.
Фоновая карта нейтральная, дороги приглушены. Белых контуров уверенности нет.
Подсказка региона показывает совместную оценку региона и оценку самой страны.

«Детали» показывает дороги с названиями/номерами, города и воду; без озеленения и гор.
Города подписаны «русское / местное», если русский вариант есть в OpenStreetMap.
У воды голубые подписи, у дорог серые; лимит и устранение пересечений сохраняют читаемость.
Это данные OSM, поэтому полного совпадения с Google Maps нет. Источники указаны внизу карты;
у ADM2 в подсказке есть год, лицензия и первоначальный поставщик. Наборы подрегионов сохраняются
в `data/boundaries`, загружаются в фоне и не зависят от включения деталей OSM.

По умолчанию шкала относительная логарифмическая:

```text
x = (score − min_level) / (max_level − min_level)
intensity = log(1 + 9x) / log(10)
```

Шкалы стран, регионов и локальных совпадений отдельные. Все наблюдавшиеся регионы сравниваются
по общей шкале, независимо от страны и viewport. Легенда показывает «Ниже → Выше» и подпись
«Внутри уровня», точные проценты доступны в таблице и подсказках. Цвет не означает вероятность
правильного ответа. Яркая точка и яркая страна могут иметь разные оценки.
Переключатель «Шкала 0–100%» задаёт общий абсолютный диапазон; выбор сохраняется в настройках.
Точность вывода малых процентов увеличена; значения почти 1 не округляются до «100%».

Точки при отдалении объединяются по близости в пределах своего региона; цвет группы отражает
суммарную поддержку, число — количество совпадений. При приближении видны отдельные координаты.
Полупрозрачные круги показывают только ориентир поиска: радиус не является измеренной точностью.
Круги могут пересекать границы, но их перекрытие не повышает непрозрачность или оценки.
Группа не получает круга вокруг своего условного центра. В режиме «Ответ» подсветка и круги скрыты.
Малочисленные небольшие круги рисуются чётко. Большие перекрывающиеся круги используют мягкий
растр ограниченного размера; маркеры координат и числа групп всегда рисуются в разрешении экрана.
