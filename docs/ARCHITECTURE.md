# Архитектура StreetJev

## Системный контекст

```text
Windows: область / окно / файл
            |
            v
Capture adapter -> Frame -> imajev worker ------> GeoEvidence
                      |                               |
                      +--> Chipoint (опционально) ----> Session
                               HTTP worker             |
                                            fusion одного кадра
                                       |
                                GeoRound (DDD)
                                       |
                         SQLite <--- Snapshot ---> Qt Map
```

Приложение — модульный монолит. Контексты «Наблюдение», «Географическое предположение»
и «Отображение» разделены границами пакетов; отдельной сети между ними нет.
Процессы imajev и Chipoint — инфраструктурные зависимости, которыми управляет тот же репозиторий.

## Препроект и критический разбор

Новый персональный Windows desktop инструмент. Частые сценарии: выбрать источник,
сделать кадр, увидеть несколько гипотез, накопить сведения и сбросить раунд.
Подтверждены сменные модели, сохранение evidence, несколько ветвей страны и независимое
накопление во времени. imajev выдаёт административные классы; координатные совпадения появляются
только при наличии кандидатов Chipoint. H3/S2 и непрерывное пространственное поле отложены.
Открытые вопросы следующих этапов: калибровочный набор, покрытие Street View,
политика перемещения между соседними регионами, допустимая задержка на целевой GPU.

## Подложка и единая карта

Существующая QGraphicsView остаётся рендерером. Из MVT Shortbread OpenStreetMap берутся
`streets`, `place_labels`, `street_labels`, `water_polygons`, `water_lines` и подписи воды.
Это приглушённые дороги, голубая вода и подписи поверх карты; без рельефа, лесов, зданий и POI.
Другие слои и неподходящие классы отбрасываются до разбора геометрии. Цвет и прозрачность
тепловой карты от переключателя подробностей не зависят.

`TileClient` использует QtNetwork, User-Agent и HTTP-кэш 256 МБ. Отдельный `VectorCache` сохраняет
разобранные упрощённые линии/подписи в gzip JSON, до 256 МБ; ключ — хэш URL и версия формата.
Учитываются Date, Age, Cache-Control, Expires; при отсутствии срока — семь дней. Файл заменяется
атомарно; ошибка необязательного кэша не ломает карту. Чтение диска, фильтрация, упрощение и запись
выполняются в QThreadPool с двумя потоками. Суммарно допускаются четыре активные загрузки/задачи.
При смене вида устаревшие запросы отменяются; debounce 180 мс, предзагрузки нет.

Масштаб рассчитывается из 512 логических пикселей на тайл, до z=14 с дальнейшим увеличением вектора;
повышенный DPI не вызывает лишних запросов. Ограничение — 96 видимых тайлов. Предыдущие перекрывающиеся
тайлы остаются приглушёнными до получения нового набора. Крупные трассы появляются с z=5,
основные дороги с z=7–9, местные с z=11–12, жилые улицы с z=14; тропинки/проезды исключены.
Геометрия упрощается с допуском extent/768. На тайл берутся до 2400 дорожных объектов по классу важности
и до 48 населённых пунктов по населению. Вода отбирается по площади до разбора геометрии:
до 256 крупных полигонов с сохранёнными отверстиями и 384 линий; ледники/канавы исключены.
Сортировка до ограничения нужна, чтобы мелкие пруды не вытесняли крупные озёра из конца MVT.
Подписи используют QStaticText, кэш раскладки и ограничение 8–60 названий по площади окна;
названия воды/дорог не повторяются в одном виде. Русское и местное имена объединяются при наличии.
Текстовые контуры на каждом кадре не строятся. Формат подготовленного кэша — `geometry-v3`.
Включение деталей не пересобирает географические полигоны/оценки.

Атрибуция находится внизу справа. Отказ сети не влияет на inference.
Политика сервера: https://operations.osmfoundation.org/policies/vector/.

ADM2 — отдельная производная проекция, не расширение модельного `GeoCatalog` внутри раунда.
`domain.subregions` задаёт сущность и правила массы: геометрические назначения приходят извне,
неразмещённая масса не нормализуется в известные районы, суммы ограничиваются ADM1/страной.
`infrastructure.subregions` получает simplified GeoJSON из geoBoundaries gbOpen, сохраняет
версию, год, лицензию и исходную геометрию в gzip JSON. Родитель ADM1 выбирается по наибольшему
пересечению (>50% площади); несогласованные родители у точки и района исключают эту массу.
STRtree выполняет назначения по исходной геометрии поставщика; три экранных упрощения используются
только для рисования. Соответствие ISO2→ISO3 собирается из той же ревизии Natural Earth.

`SubregionLayer` запрашивает до двух стран одновременно, хранит до восьми наборов в памяти,
пересчитывает поддержку по текущему раунду/кадру после загрузки, не изменяя агрегат.
Подготовка геометрии, поиск родителей и дисковый кэш выполняются в QThreadPool.
Подготовленные WKB, родители, точки подписей и три упрощения сохраняются отдельно в построчном gzip JSON.
Сигнатура включает версию формата, параметры исходного файла и хэш геометрии родителей ADM1;
невалидный кэш перестраивается. Чтение построчное, большой исходный JSON разбирается с Python callbacks
для координат, чтобы C-декодер не удерживал GIL на всё время разбора страны; запись также порционная.
На подробном масштабе создаются только видимые Qt items, до 240, с кэшем 600 путей.
Когда районов слишком много, остаются только поддержанные; остальные контуры появляются при приближении.
Заливка ADM1 ослабляется при показе дочерней поддержки. Сброс немедленно убирает поддержку,
а поздняя загрузка границ не восстанавливает старый раунд. Получение геометрии не двигает камеру.
Сбой сети оставляет обзорную карту; старый кэш ADM2 доступен offline. Версии и лицензии наборов
показываются в подсказке атрибуции и входят в экспорт. SQLite и хэш модельного каталога не меняются;
ADM2 правильного ответа выводится из уже сохранённых координат. Параметры моделей не переобучаются.

Доменный `LocalPoint` сохраняет ID, исходные координаты, страну, admin1 и массу совпадения Chipoint
после преобразования scores температурой и поправки по покрытию. Масса абсолютная: она уже
учитывает неразмещённые точки и неизвестность. Поправки по признакам
уменьшают её; fusion умножает на вес эксперта. imajev не создаёт координатных данных.

`GeoRound` усредняет массы точек по новизне всех принятых кадров; повторный кадр не усиливает оценку,
а отсутствие координатных данных оставляет часть массы не локализованной. В snapshot результат
ограничивается как суммой страны, так и массой региона. Сумма точек не нормализуется искусственно до 100%.
Основные country/admin1 оценки не зависят от локального слоя. Refine сохраняет локальные данные
Chipoint через повторное объединение, disable/reset корректно очищают их. Evidence и snapshot хранят
точки, исходные координаты также остаются в raw_json; калибратор пересоздаёт их из кандидатов.

Сетка `LocalCell` порядка 10 км также сохраняется для совместимости журнала и replay, но UI использует
точные `LocalPoint`, а не центры ячеек. Старые записи без `points` читаются с пустым набором точек.

`MapView` показывает уровни одновременно: `CountryOutline` рисует цветной контур страны,
admin1 использует спокойную заливку, `LocalOverlay` рисует точечные совпадения. Палитра общая,
относительные шкалы отдельные по уровням; все наблюдавшиеся admin1 используют одну шкалу.
В абсолютном режиме общий диапазон 0–1. Иерархическая таблица показывает исходные числа.

Сегменты контуров подготавливаются один раз и отрисовываются через `drawLines`. Нет полного
`setClipPath` по береговой линии и двойного широкого `drawPath` при каждом pan/zoom: на сложных
странах они давали сотни миллисекунд задержки. На общей границе контур с большей поддержкой сверху.

У больших контуров есть обзорный набор сегментов (упрощение в координатах Mercator с допуском
0,08, используется только при scale × DPR ≤ 12). Это меняет только цветную обводку; полигоны
и индекс сцены не перестраиваются при zoom. Сегменты объединены в блоки по 128 с bounding box:
блоки вне exposed rect пропускаются. `MapPolygon.shape()` возвращает исходный заполненный контур,
не строя stroked path для проверки клика. Во время настоящего drag/wheel `MapView` отключает
сглаживание полигонов и восстанавливает его после 140 мс покоя. Коллизии подписей проверяются
по соседним ячейкам экранной сетки 64 px, а не по всем уже показанным названиям.

`TileRasterCache` хранит до 64 МиБ прозрачных рисунков дорог/воды. `RoadTile` растеризует их один
раз для текущего уровня тайлов и переиспользует при движении; смена данных создаёт новый ключ.
Размер растра учитывает DPR и число тайлов, чтобы весь текущий вид помещался в кэше без постоянного
вытеснения. Пустые тайлы не рисуются. При экранной ширине тайла >1024 px используются исходные
векторы: предельный уровень источника не должен превращать дороги в толстые полосы. Подписи
рисуются отдельно в разрешении экрана. HTTP-кэш и подготовленные векторы на диске не меняются.

`cluster_points` группирует близкие точки по устойчивой экранной сетке с дискретными ступенями zoom,
не объединяя разные страны/admin1. Группировка не меняет домен и сохраняет сумму масс. Один
кэшируемый QImage кругов заменяет тысячи scene items. Полноэкранная промежуточная копия при pan
не создаётся; маркеры рисуются прямо в viewport. Для небольшого числа кругов композиция ограничена
их прямоугольниками, чтобы не обрабатывать пустую прозрачную часть экрана. `_render()` оставлен
только для снимков и проверок пикселей. Круги сначала рисуются непрозрачно, затем весь слой
получает alpha 0,15: перекрытие не повышает непрозрачность. Одиночные совпадения имеют круг поиска
с настраиваемым радиусом, группа — только маркер с числом точек; двойной клик раскрывает её.
Радиус приближённо учитывает масштаб Mercator на широте точки и не является измеренной ошибкой модели.
Отдельные официальные admin2/admin3 пока не загружаются. Навигация и радиус не вызывают inference.

Крупные круги рисуются в отдельном растре с длинной стороной 256–640 пикселей в зависимости
от числа пересечений, затем плавно увеличиваются. Небольшие круги при малом их числе и все
точечные маркеры сохраняют полное разрешение/DPI. Координаты, массы и радиус не меняются.
Заливки слабее круга, полностью покрывшего viewport, пропускаются как полностью скрытые.
Проекции, цвета и радиусы кластеров подготавливаются при смене набора/ступени zoom, а не при pan.

## Разметка и офлайн-калибровка

Кнопка «Ответ» включает специальный режим клика. Обратная проекция карты возвращает координаты,
инфраструктурный `GeographicLocator` определяет страну и admin1 даже для не подсвеченного региона.
`Session.label` проверяет соответствие каталогу и сначала сохраняет запись, затем публикует её в UI.
Таблица `ground_truth` содержит одну исправляемую отметку на раунд и даты создания/изменения.
Отметка не участвует в выводе модели и не меняет накопленные оценки. Новые кадры в размеченный раунд
не принимаются; запущенные ранее дополнительные запросы по его кадрам могут завершиться.

`scripts/calibrate.py` — отдельная точка входа. `infrastructure.calibration` читает согласованный снимок
SQLite в режиме read-only, восстанавливает исходные ответы и выполняет тот же пересчёт, что приложение.
Для imajev используется исходный choice readout; для Chipoint — исходные кандидаты/оценки и сохранённые
плотности тайлов. Сетевых обращений, повторных inference и повторного применения старых поправок нет.
Обрабатываются только активные дополнения Chipoint; демо, несовместимые данные и другие версии
моделей исключаются с объяснением в отчёте. Исходная история не перезаписывается.

`application.calibration` не зависит от UI, SQLite или HTTP. Она получает размеченные раунды и функцию
пересчёта. Географические ячейки 0,25° делятся воспроизводимо (seed 17), минимум 12 ячеек:
не менее 8 для подбора и 4 для проверки. Все кадры и повторы раунда остаются вместе.
Два прохода координатного поиска минимизируют среднее country NLL и joint region NLL на обучающей части.
При отсутствии меток регионов используется только country NLL. Региональные ветви остаются фиксированными;
отсутствующая ветвь получает равномерное условное распределение для NLL и не считается успешным
предсказанием admin1. Покрытие правильных ветвей выводится отдельно. Unknown сохраняет прежнюю семантику.

Температуры imajev преобразуют `softmax(log(p) / T)`, Chipoint — `softmax(score / T)`.
Нулевые вероятности не превращаются в новые гипотезы. Метод опирается на идею
[temperature scaling (Guo et al., 2017)](https://proceedings.mlr.press/v70/guo17a.html),
но не доказывает калиброванность конкретной географической системы.
Дополнительно подбираются вес второго эксперта и силы трёх мягких поправок.

Проверочная часть не влияет на поиск. `--apply` допускает новый профиль только при снижении её
совместной ошибки без ухудшения country/admin1 accuracy; исходный профиль сохраняется для отката.
Профиль связан с версиями обеих моделей и хешем кодов каталога; неизвестная версия использует
обычные параметры. Повреждённый профиль не препятствует запуску UI и отображается как ошибка в статусе.
Повторный подбор на одной и той же проверочной части не заменяет независимую контрольную выборку.
Обучение весов моделей и сохранение изображений не входят в этот алгоритм.

Зависимости направлены к домену. `bootstrap.py` и настройка workers в presentation связывают
адаптеры с портами; domain/application не импортируют Qt, HTTP или CUDA.
Модели никогда не изменяют UI или состояние раунда напрямую.

## Data flow

1. Кнопка, горячая клавиша или таймер запускает один `AnalysisWorker` с текущим round ID.
2. Захват возвращает JPEG (до 1280 px по длинной стороне) и миниатюру 32 × 32.
3. Сравнение миниатюр определяет novelty; почти повторный кадр не отправляется модели.
4. imajev отвечает по всем 240 странам. Для нескольких кандидатов делаются условные
   региональные вопросы; при высоком unknown региональный проход пропускается.
5. Anti-corruption layer проверяет полный набор кодов, числа и формат ответа.
6. `Session` отвергает ответ старого раунда. Домен строит новое состояние без изменения старого.
7. SQLite атомарно сохраняет raw evidence и snapshot. Только после успеха публикуется состояние.
8. UI обновляет полигональную карту и список гипотез. Снимок экрана остаётся только в памяти.
9. Если включён Chipoint и его канал свободен, тот же подготовленный кадр параллельно
   отправляется локальному retrieval-сервису. Основной ответ не ждёт дополнительного.
10. Координаты top-64 локально сопоставляются с Natural Earth. `Session.supplement` заменяет
    evidence соответствующего кадра линейной смесью и пересобирает раунд с исходными весами.
    Повторного учёта кадра нет; raw responses сохраняются раздельно. Подробнее —
    [ADR-0006](adr/0006-optional-chipoint.md).
11. В исходный запрос imajev входят ещё два вопроса: сторона движения и полушарие,
    оба с вариантом «не определить». Локальный справочник стороны движения перенесён
    из guess-map; полушария стран и регионов определяются по границам Natural Earth.
    Противоречие уменьшает поддержку, снятая масса переходит в unknown. Максимальная
    поправка — 45% для движения и 25% для полушария; это эвристики, не калибровка.
12. После обоих ответов imajev проверяет до `beam` лучших стран Chipoint, для которых
    ещё нет его регионального ответа. Основной результат и Chipoint уже видны на карте.
    `Session.refine` сохраняет дополнительные ответы в исходном наблюдении, оставляя
    прежние raw answers внутри JSON, и пересобирает тот же раунд. Нового кадра нет.
    При отключении Chipoint завершённые региональные ответы imajev остаются, его
    страновые оценки восстанавливаются; незавершённые уточнения игнорируются.
13. Опциональная поправка покрытия использует тот же слой Google `svv`, что и guess-map:
    до 8 тайлов z=12 рядом с сильнейшими кандидатами разных стран, запросы параллельны,
    каждый ограничен 2 секундами. В памяти кэшируются только числовые плотности.
    Штраф проверенной точки не превышает 15%; сеть/неизвестный формат/непроверенная точка
    дают нейтральный результат. Это плотность линий в окрестности, не вероятность выбора
    локации игровой картой и не покрытие всей страны. Настройку можно выключить.

## Ключевые интерфейсы

Порты определены через `typing.Protocol` в `application/ports.py`:

```python
class GeoExpert(Protocol):
    def infer(self, frame: Frame) -> GeoEvidence: ...

class RoundRepository(Protocol):
    def start(self, snapshot: RoundSnapshot) -> None: ...
    def append(self, snapshot, frame, evidence, novelty) -> None: ...
    def supplement(self, snapshot, frame, evidence, weight) -> None: ...
    def refine(self, snapshot, frame, evidence) -> None: ...
    def disable_supplements(self, snapshot) -> None: ...
```

Для нового эксперта достаточно реализовать `infer`. Его сырые similarity/logits нельзя
передавать как probabilities: адаптер обязан преобразовать их в сопоставимый формат.
Chipoint сохраняет пространственные кандидаты в raw JSON и `LocalPoint`; адаптер также агрегирует их
по административным полигонам. Офлайн-калибратор пересчитывает эти же данные. Непрерывное поле отложено.

## Инварианты и накопление

`GeoRound` — aggregate root. `Frame`, `GeoEvidence`, `Distribution`, `Place` — объекты-значения.
Результат модели неизменяем; накопленное состояние принадлежит одному раунду.

```text
weight_t = novelty_t × (1 − unknown_t)
score_t(c) = Σ weight_i × P_i(c) / Σ weight_i
```

Используется линейное объединение распределений (`weighted_linear_v2`). Оно не требует
считать кадры независимыми свидетельствами и не возводит повторяющуюся оценку в степень.
Результат — выпуклая комбинация: оценка страны не превышает максимум её оценок на учтённых кадрах.
При нулевом общем весе остаётся равномерное распределение, которое UI показывает как отсутствие данных.
Unknown уменьшает вес, полностью неизвестный кадр не меняет накопленные оценки.

Это мера поддержки гипотезы ответами модели, а не калиброванная вероятность правильного ответа.
Совпадения лидеров учитываются только как диагностика согласия. На одинаково ошибочных кадрах
средняя оценка тоже будет ошибочной. Веса яркостной новизны остаются эвристикой.
Старые snapshots не переписываются; новая версия алгоритма записывается в каждом новом snapshot.

Региональные распределения также усредняются, условны и отдельно нормализованы внутри страны. Их вес
дополнительно умножается на вероятность страны в текущем наблюдении. UI использует
совместную массу; сумма регионов страны равна её массе. Неисследованные регионы на карту
не выводятся. `unknown` не интерпретируется как место на карте.

В `linear_experts_v2` региональные ответы двух экспертов объединяются с весами 65/35 и unknown,
без повторного умножения на исходную оценку страны каждого эксперта: условный вопрос уже
предполагает эту страну. Совместная масса региона по-прежнему ограничена итоговой массой страны.
Это позволяет использовать проверку imajev даже для страны, найденной только Chipoint.

Snapshot содержит отдельно последнее наблюдение, его региональные ветви и unknown. Значения
предыдущих региональных запросов не выдаются за последний кадр. Подробнее о смене формулы:
[ADR-0005](adr/0005-confidence-and-map-scale.md).

Повторный frame ID, повторная миниатюра и неверный round ID не меняют агрегат.
Ошибка входных данных не допускает частичного обновления. Ошибка БД не публикует несохранённое состояние.

## Технологические решения

| Решение | Выбор | Обоснование |
|---|---|---|
| Desktop | Python 3.12 + PySide6 | Уже выбран Python; нативные окна, фоновые задачи |
| Карта | QGraphicsView + Natural Earth | Автономная работа, без браузера и тайлов |
| Модель | Официальный imajev API | Поддержка decision readout и unknown |
| Хранение | SQLite WAL | Локальная транзакция без отдельного сервера БД |
| Конкурентность | Один основной + один необязательный worker, UI-поток | Каждый канал без очереди, imajev не ждёт Chipoint |
| Chipoint | Отдельный процесс, один SigLIP2 tower по умолчанию | Включается независимо, галерея читается блоками |
| Захват | mss / Pillow PrintWindow | Область в физических пикселях, отдельное окно |

## Режимы отказа

| Сбой | Влияние | Обработка |
|---|---|---|
| Сервис не запущен / timeout | Нет нового evidence | Сообщение, остановка автозахвата |
| Chipoint не отвечает / занят / timeout | Нет дополнительного evidence | imajev продолжается, короткий статус и подробная подсказка |
| Закрытое / свёрнутое окно | Нет кадра | Повторный выбор источника |
| Чёрный результат PrintWindow | Нет пригодного кадра | Предложение выбрать область |
| Занята горячая клавиша | Нет глобального действия | Явный статус, кнопки доступны |
| Ошибка ответа / коды / NaN | Evidence отвергнуто | Состояние не меняется |
| Сброс во время inference | Ответ устарел | Проверка round ID перед приёмом |
| SQLite read-only / полный диск | Сохранение не состоялось | Старое состояние сохраняется |
