# ADR-0001: стек и границы приложения

Дата: 2026-09-30. Статус: принято.

## Контекст

В репозитории уже Python 3.12. Требуется Windows desktop с отдельным окном карты,
быстрым захватом и доступом к локальному GPU-сервису.

## Варианты и решение

PySide6, web UI и Tauri рассмотрены. Выбран Python + PySide6: меньше языков, нативный
доступ к окнам и отсутствие обязательного браузерного сервера. Архитектура — модульный
монолит с DDD-ядром и портами. imajev выделен в процесс из-за CUDA-зависимостей.

## Последствия

Проще отлаживать pipeline в одном репозитории. UI зависит от Qt; карта реализуется
через QGraphicsView. Пространственная сетка добавляется после появления координатного эксперта.

Остальные решения: [хранение](0002-storage.md), [конкурентность](0003-concurrency.md),
[ошибки](0004-errors.md).
