# ADR-0003: один inference в работе

Дата: 2026-09-30. Статус: принято.

## Контекст и варианты

GPU-запрос медленнее UI. Блокирующий вызов замораживает окно, очередь снимков показывает
устаревшие результаты, конкурентные GPU-запросы увеличивают память и задержку.

## Решение

Один QRunnable в QThreadPool. Новые тики при busy пропускаются. Worker возвращает исходный
round ID, Session проверяет его. Qt widgets и агрегат изменяются только UI-потоком.

## Последствия

UI остаётся отзывчивым, сброс безопасен. После сброса старый inference продолжает исполняться
до завершения или timeout; до этого новый запрос не запускается. При закрытии приложение ждёт worker.
