# ADR-0002: журнал в SQLite

Дата: 2026-09-30. Статус: принято.

## Контекст и варианты

Нужно сохранять outputs для будущего сравнения моделей. Только RAM теряет историю;
JSONL не даёт простой атомарности evidence + snapshot; серверная БД здесь избыточна.

## Решение

SQLite WAL, таблицы `rounds` и `observations`. Данные сохраняются до публикации состояния.
Сброс создаёт новый раунд и сохраняет старый журнал. Кадры на диск не записываются.

## Последствия

Простая локальная эксплуатация и offline-анализ. Восстановление и миграции схемы предстоит
добавить перед следующей версией. Экспорт JPEG для размеченного benchmark потребует отдельной настройки.
