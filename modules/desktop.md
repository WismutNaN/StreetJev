# Модуль: настольное представление

Расположение: `src/streetjev/presentation/`; composition root: `src/streetjev/bootstrap.py`.
Отвечает за окно карты, источник снимков, действия пользователя и состояния интерфейса.

Публичные типы: `MainWindow`, `MapView`, `RegionOverlay`, `GlobalHotkeys`, `AnalysisWorker`.
Зависимости: PySide6 и сценарии application; конкретные адаптеры выбираются здесь и в bootstrap.

Все изменения `Session` и Qt widgets выполняются в UI-потоке. Worker выполняет только захват,
проверку novelty и inference, затем отправляет сигналы. Основной запрос один; независимо от него
может работать один `SupplementWorker` Chipoint. Ни один канал не создаёт очередь кадров.
Сброс создаёт новый ID; поколение переключателя дополнительно отсеивает ответы после disable.
Поздний дополнительный ответ передаётся в `Session.supplement`; UI не реализует fusion.

Региональные полигоны отображаются только для исследованных стран. Цвет зависит от абсолютной
совместной массы через отдельный `HeatScale`; этот модуль не меняет доменные оценки.
По умолчанию контраст нормализован по текущему слою и усилен логарифмом; легенда и подсказки
показывают исходные проценты. Есть абсолютная шкала и сравнение раунда с последним кадром.
Демо маркировано и не делает снимков.
Компоновка — `layout.py`: две компактные строки действий, карта и карточка гипотез поверх неё.
`auto_focus.py` выбирает общий охват группы лидеров; при разбросе остаётся мир, ручная навигация
приостанавливает автофокус. Настройки — отдельный диалог; пояснения — подсказки.
Сценарии и состояния: [UI.md](../docs/UI.md).
