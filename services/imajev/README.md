# Локальный сервис imajev

Этот каталог — часть StreetJev. `manage.py` устанавливает официальную реализацию
в `.runtime/imajev/source`, отдельное Python-окружение — в `.runtime/imajev/.venv`,
веса и все кэши сервиса — в `.runtime/` корня проекта. Никакой каталог с моделью вне
StreetJev создавать не нужно. Большие файлы исключены из Git.

```powershell
uv run python services/imajev/manage.py setup
uv run python services/imajev/manage.py start
uv run python services/imajev/manage.py status
```

`setup --skip-weights` устанавливает только окружение. Обычный `setup` можно повторить
после обрыва сети. `start --port 8766` меняет порт; укажите тот же адрес в приложении.
Рекомендуемый общий запуск после установки: `./run.ps1 -WithModel`.

Исходники и веса закреплены в [manifest.json](manifest.json). Базовый checkpoint
скачивается официальным скриптом с проверкой размера репозитория модели. Список реально
установленных Python-пакетов сохраняется в `.runtime/imajev/installed.txt`.
Зависимости сервиса разрешаются установщиком; это не переносимый lock GPU-окружения.
Отдельное окружение не добавляет PyTorch в зависимости графического приложения.

Сервис слушает `127.0.0.1:18765`, запросы: `POST /v1/systemone`, состояние: `GET /v1/models`.
Порт отличается от upstream-default 8765, чтобы избежать конфликта с уже работающим здесь сервисом.
В запросе передаются multipart-поля `request` (JSON) и `image` (JPEG).
В одном choice-вопросе разрешено до 254 вариантов; отдельный decision code занят `unknown`.
API возвращает вероятности, условные на известном ответе, и `unknown_probability` отдельно.

На Windows используется обычный torch backend с одной перестановкой вариантов.
Оптимизированный `--fast` путь автора требует дополнительных средств сборки/Triton
и по умолчанию не включается. Авторские цифры задержки на H100 здесь не обещаются.

Диагностика:

- «Нет соединения» — дождитесь загрузки GPU-модели, проверьте `status` и журнал.
- CUDA недоступна — проверьте драйвер NVIDIA и вывод установщика; CPU будет очень медленным.
- Нехватка памяти GPU — освободите VRAM от других моделей.
- HTTP 422 — приложение показывает тело ошибки, включая превышение token budget.
- После работы с отдельным терминалом завершите сервис Ctrl+C.

Официальные исходники имеют лицензию Apache-2.0; лицензии весов и базовой модели
сохраняются в скачанных репозиториях. StreetJev не модифицирует upstream-файлы.
